# 验证说明

在项目根目录运行，仅需要 Node.js，无需安装 npm 包、Python 或 PyTorch：

```sh
node tools/check-local.js
node tools/verify.js
node tools/verify-flow.js
```

## 自动检查

| 命令 | 检查内容 |
| --- | --- |
| `check-local.js` | 运行资源完整性、脚本语法、无外部运行请求、经典脚本入口 |
| `verify.js` | 12 张测试图的 JS / PyTorch 数值对照、注意力归一化、30 个内置样例 |
| `verify-flow.js` | 真实 token 数、867 条注意力依赖、单光点时序、亮度单调性与 29 步详解覆盖 |

检查输出写入本地 `work/`，目录由检查脚本自动创建，不纳入 Git。

本次导出的模型在数值对照中，最大分类得分误差约 `1.31e-6`，最大注意力权重误差约 `4.17e-7`；12 张对照图的预测全部一致，30 个内置样例预测正确。

## 浏览器验证

使用本机 HTTP 预览完成了手写输入、样例选择、播放暂停、单步与调速、固定 51 个节点、各类单光点传输、概率渐亮和四项过程详解检查。详解包括目的、流程、输入、输出，展开时暂停，切换步骤同步更新，更换输入后复位。

直接双击 HTML 的入口完成了资源与语法静态检查；自动浏览器验证使用 HTTP，未实际执行文件协议测试。浏览器对 Canvas、SVG 和鼠标/触控事件的支持会影响实际体验。

## 模型指标

模型训练、验证和测试划分见 `model/manifest.json`；训练历史见 `docs/training-history.json`。MNIST 独立测试准确率为 99.01%，不代表鼠标手写识别准确率。重新训练会生成新的模型和对照夹具，应重新运行以上检查。
